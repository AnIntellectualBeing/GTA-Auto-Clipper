GOOD TO KNOW

Before you download.

Does it need a YouTube API key?

No. This tool renders video files already on your computer. Stream finding and capture belong to the separate GTA Auto Clipper workflow.

Does it automatically find the streamer’s face?

No. Supply a separate facecam video and matching gameplay video. If you only have a composite recording, crop the tracks manually first.

Are captions automatic?

No. Supply an accurately timed UTF-8 SRT file when you want captions. The tool renders the supplied phrases; it does not transcribe speech.
